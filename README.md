# K-Legonara

K-Legonara is an AI, digital twin, manufacturing, marketplace, and knowledge platform initiative.

## Repository structure

- `docs/blueprint/` — product and platform blueprints
- `docs/design/` — brand, UX, UI, and design-system documentation
- `docs/architecture/` — technical architecture documentation
- `docs/adr/` — architecture decision records
- `apps/` — deployable applications
- `packages/` — shared packages and libraries
- `assets/` — shared visual and media assets
- `.github/` — GitHub configuration and workflow files
