# K-Legonara Design 문서 안내

이 디렉터리의 두 문서는 서로 대체 관계가 아니라 역할이 다른 공동 기준 문서다.

## 기준 문서

### Design Guideline

[`K-Legonara_Design_Guideline_v1.md`](K-Legonara_Design_Guideline_v1.md)는 K-Legonara의 승인된 디자인 방향을 정의한다.

- Neo Aqua `#22C7B8` 중심의 브랜드 언어.
- 정보 계층, 3열 플랫폼 레이아웃, Hero, Sidebar와 Card 시스템.
- AI, Digital Twin, Manufacturing, Marketplace, Knowledge, Enterprise 영역별 UI 원칙.
- 타이포그래피, 간격, 컴포넌트, 모션과 데이터 시각화 기준.

### Design Architecture & Workflow

[`K-Legonara_Design_Architecture_and_Workflow.md`](K-Legonara_Design_Architecture_and_Workflow.md)는 장기 디자인 생산과 인계를 위한 Baseline 1.0.0이다.

- Design Token과 Component Library 운영.
- Figma 파일, Variables, Branch와 리뷰 규칙.
- ChatGPT와 이미지 생성 도구를 이용한 제작 절차.
- 협업 역할, 버전 관리, 변경 요청과 ADR 예시.
- 산출물, 완료 정의, Handoff와 품질 체크리스트.

실제 화면을 만들 때는 Guideline으로 시각·경험 방향을 결정하고, Architecture & Workflow로 제작·검토·인계 과정을 운영한다. 두 문서가 충돌하면 임의로 하나를 선택하지 않고 `docs/adr/`에 결정과 영향을 기록한다.

## 참고 이미지

[`../../assets/design/references/kidultverse-dashboard-layout-reference-2026-07-29.png`](../../assets/design/references/kidultverse-dashboard-layout-reference-2026-07-29.png)는 초기 레이아웃 탐색에 사용된 참고 이미지다.

이 이미지에서 참고할 대상은 Header, Left Navigation, 중앙 Hero, 카드형 콘텐츠, Right Sidebar와 전체 여백 구조다. Purple 색상, KidultVerse 브랜드, 문구, 상품과 Creator 콘텐츠는 K-Legonara 최종 기준이 아니다. K-Legonara의 최종 브랜드 기준은 두 문서에 정의된 Neo Aqua Design Language다.
