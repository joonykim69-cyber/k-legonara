# Design Reference Assets

이 디렉터리는 최종 제품 자산이 아니라 디자인 탐색과 의사결정의 출처를 보존한다.

## KidultVerse dashboard layout reference

- 파일은 [`kidultverse-dashboard-layout-reference-2026-07-29.png`](kidultverse-dashboard-layout-reference-2026-07-29.png)이다.
- 사용자 제공 원본명은 `ChatGPT Image 2026년 7월 29일 오후 02_45_50.png`이다.
- 참고 요소는 3열 레이아웃, Header, Left Navigation, Hero, 카드 시스템과 Right Sidebar다.
- Purple 색상, KidultVerse 로고, 콘텐츠, 문구와 상품 이미지는 K-Legonara의 제품 자산이 아니다.
- 최종 K-Legonara 화면은 Neo Aqua Design Language와 K-Legonara 정보 구조를 따라야 한다.
- 원본 자산의 별도 라이선스가 확인되지 않았으므로 제품 UI나 마케팅 산출물에 직접 재사용하지 않는다.
